# CalorieCam

Android-застосунок: фотографуєте страву — застосунок пропонує назву (розпізнавання на пристрої), ви підтверджуєте/змінюєте порцію, і калорії рахуються автоматично. Плюс профіль з денною нормою калорій, трекер води, вага тіла з графіком прогресу, поради/вправи та нагадування про прийоми їжі.

## Як це працює

1. **Фото** — камера (через системний застосунок камери) або вибір із галереї (Photo Picker, без запиту дозволів на сховище).
2. **Розпізнавання** — [ML Kit Image Labeling](https://developers.google.com/ml-kit/vision/image-labeling) працює повністю на пристрої (модель вбудована в APK, інтернет не потрібен, без API-ключів). Отримані мітки (англійською) зіставляються з локальною базою продуктів; коли модель дає лише загальну категорію ("Fruit", "Baked goods" тощо), застосунок підбирає найпоширеніші варіанти з цієї категорії замість порожнього результату.
3. **Підтвердження порції** — користувач бачить варіанти розпізнавання (чипси), може обрати інший продукт через пошук по базі, або ввести назву й калорійність вручну. Для розпізнаних продуктів показується коротка інформація про користь і вітаміни. Розмір порції задається повзунком або полем вводу.
4. **Збереження** — запис (фото, назва, грами, ккал, Б/Ж/В) зберігається в локальній базі Room. Головний екран показує кільце прогресу калорій за день, білки/жири/вуглеводи та список записів.

Розпізнавання зображень — це best-effort підказка (ML Kit використовує загальну модель класифікації, а не спеціалізовану на їжі), тому ручний пошук/введення завжди доступні як надійний резервний варіант.

## Додаткові можливості

- **Профіль** (стать/вік/зріст/вага/активність/ціль) → денна норма калорій за формулою Міффліна-Сан Жеора.
- **Трекер води** — швидка кнопка "+склянка" з денною нормою (~30 мл/кг ваги).
- **Прогрес** — стовпчиковий графік калорій за тиждень/місяць і графік ваги тіла з можливістю додавати нові виміри.
- **Поради та вправи** — рекомендації для схуднення/набору маси, загальні поради з харчування, три комплекси вправ (кардіо, силові, розтяжка).
- **Нагадування** — щоденні push-сповіщення про сніданок/обід/вечерю (вимикається/вмикається в профілі).
- **Резервне копіювання** — експорт усіх даних (профіль, журнал їжі, вага, вода) у JSON-файл через системний вибір файлу та імпорт назад (наприклад, при зміні телефону). Фото до бекапу не входять — лише метадані записів.

## Структура проєкту

```
app/src/main/java/com/caloriecam/app/
  data/        Room (FoodLogEntry/WeightEntry/WaterEntry + DAO, AppDatabase), NutritionRepository,
               UserProfile(+Repository), TipsContent, BackupData/BackupManager
  ml/          FoodLabeler — обгортка над ML Kit Image Labeling
  notify/      NotificationHelper, ReminderWorker/Scheduler — щоденні нагадування (WorkManager)
  ui/          Compose-екрани: HomeScreen, CaptureScreen, ProfileScreen, StatsScreen, TipsScreen
  util/        PhotoStore (зберігання фото), BitmapUtils (декодування з урахуванням EXIF)
app/src/main/assets/nutrition_uk.json   Локальна база 136 продуктів (ккал/Б/Ж/В на 100 г,
                                          для ~55 — користь і вітаміни)
```

## Стек

Kotlin, Jetpack Compose (Material 3), Room, DataStore Preferences, WorkManager, ML Kit Image Labeling (bundled/offline), Coil, kotlinx.serialization. `minSdk 26`, `targetSdk/compileSdk 34`.

## Збірка

Потрібен Android Studio (Koala+) або Android SDK + інтернет-доступ до `google()`/`mavenCentral()` для завантаження залежностей — у поточному хмарному середовищі розробки немає Android SDK і немає мережевого доступу до репозиторію Google Maven, тож зібрати APK тут неможливо. Відкрийте каталог `android-calorie-app/` в Android Studio — вона сама підтягне Gradle-обгортку (уже додана, `gradlew`/`gradlew.bat`) та потрібний SDK.

```
./gradlew assembleDebug   # зібрати debug APK
./gradlew installDebug    # встановити на підключений пристрій/емулятор
```

## Відомі обмеження

- База продуктів (`nutrition_uk.json`) охоплює 136 поширених страв і продуктів (включно з українськими: борщ, вареники, деруни, голубці, сирники тощо). Легко розширюється — просто додайте новий об'єкт у JSON.
- Точність авто-розпізнавання обмежена загальною моделлю ML Kit; для страв, яких немає в базі або які модель не впізнала, передбачено ручний пошук і ручне введення калорійності.
- Дозвіл на камеру запитується під час першого використання; для галереї дозволи не потрібні (Photo Picker). Дозвіл на сповіщення (Android 13+) запитується лише при вмиканні нагадувань у профілі.
- Нагадування реалізовані через самопланований ланцюжок WorkManager (без `SCHEDULE_EXACT_ALARM`), тому час спрацювання може відхилятись на кілька хвилин.
- База даних версії 2 (додано таблиці ваги/води) використовує `fallbackToDestructiveMigration()` — якщо застосунок вже стоїть на пристрої зі старою версією БД, локальні дані буде очищено при першому оновленні. На нових встановленнях це не стосується.
