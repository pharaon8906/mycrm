# CalorieCam

Android-застосунок: фотографуєте страву — застосунок пропонує назву (розпізнавання на пристрої), ви підтверджуєте/змінюєте порцію, і калорії рахуються автоматично. Всі записи зберігаються локально по днях.

## Як це працює

1. **Фото** — камера (через системний застосунок камери) або вибір із галереї (Photo Picker, без запиту дозволів на сховище).
2. **Розпізнавання** — [ML Kit Image Labeling](https://developers.google.com/ml-kit/vision/image-labeling) працює повністю на пристрої (модель вбудована в APK, інтернет не потрібен, без API-ключів). Отримані мітки (англійською) зіставляються з локальною базою продуктів.
3. **Підтвердження порції** — користувач бачить топ-варіанти розпізнавання (чипси), може обрати інший продукт через пошук по базі, або ввести назву й калорійність вручну, якщо страви немає в базі. Розмір порції (грам) задається повзунком або полем вводу.
4. **Збереження** — запис (фото, назва, грами, ккал, Б/Ж/В) зберігається в локальній базі Room. Головний екран показує денний підсумок калорій і список записів з можливістю видалення.

Розпізнавання зображень — це best-effort підказка (ML Kit використовує загальну модель класифікації, а не спеціалізовану на їжі), тому ручний пошук/введення завжди доступні як надійний резервний варіант.

## Структура проєкту

```
app/src/main/java/com/caloriecam/app/
  data/        Room (FoodLogEntry, FoodLogDao, AppDatabase) + NutritionRepository (база продуктів)
  ml/          FoodLabeler — обгортка над ML Kit Image Labeling
  ui/          Compose-екрани: HomeScreen (журнал), CaptureScreen (фото → підтвердження)
  util/        PhotoStore (зберігання фото), BitmapUtils (декодування з урахуванням EXIF)
app/src/main/assets/nutrition_uk.json   Локальна база ~75 продуктів (ккал/Б/Ж/В на 100 г)
```

## Стек

Kotlin, Jetpack Compose (Material 3), Room, ML Kit Image Labeling (bundled/offline), Coil, kotlinx.serialization. `minSdk 26`, `targetSdk/compileSdk 34`.

## Збірка

Потрібен Android Studio (Koala+) або Android SDK + інтернет-доступ до `google()`/`mavenCentral()` для завантаження залежностей — у поточному хмарному середовищі розробки немає Android SDK і немає мережевого доступу до репозиторію Google Maven, тож зібрати APK тут неможливо. Відкрийте каталог `android-calorie-app/` в Android Studio — вона сама підтягне Gradle-обгортку (уже додана, `gradlew`/`gradlew.bat`) та потрібний SDK.

```
./gradlew assembleDebug   # зібрати debug APK
./gradlew installDebug    # встановити на підключений пристрій/емулятор
```

## Відомі обмеження

- База продуктів (`nutrition_uk.json`) охоплює ~75 поширених страв і продуктів (включно з українськими: борщ, вареники, деруни, голубці, сирники тощо). Легко розширюється — просто додайте новий об'єкт у JSON.
- Точність авто-розпізнавання обмежена загальною моделлю ML Kit; для страв, яких немає в базі або які модель не впізнала, передбачено ручний пошук і ручне введення калорійності.
- Дозвіл на камеру запитується під час першого використання; для галереї дозволи не потрібні (Photo Picker).
